RADAR V3.1 — by twagirumukiza

Progression de difficulté :
- niveaux 1 à 3 : les menaces rouges restent visibles ;
- à partir du niveau 4 : une menace n'est visible et cliquable QUE lorsque la traînée verte du radar passe sur elle ;
- le faisceau continue à tourner dans le sens horaire ;
- la zone de révélation correspond à la traînée derrière le bord lumineux ;
- aux niveaux supérieurs, la fenêtre de visibilité se réduit progressivement ;
- vitesse et nombre de menaces continuent également d'augmenter ;
- toutes les mécaniques de Radar V3 sont conservées.
